# Build notes — One Word From Your Ex

The entry is a single word, the word an ex would use to describe the
entrant. The program writes that one word to the output entry file and
nothing else.

The first draft chose the word unavailable. It is honest and it is the
word most people reach for first, which is exactly why it was revised
away from: the therapy-speak answer is the one most entries will send,
so it cannot stand out.

The final word is almost. It is not an insult word, which is the sharp
turn in it. An ex saying almost means almost the one, almost enough,
almost worth staying for, and the sentence never finishes. It lands
instantly in six letters, it cannot be swapped for a near synonym
without losing its edge, and it stings because it is plainly true and
the entrant plainly knows it.

Verification: the program was run twice, once per draft, and the output
file was read back each time. The final run writes the word almost,
six bytes, no trailing newline, a single word of plain letters. The
gate needs one to twenty-four characters of text, so six characters
passes comfortably.
